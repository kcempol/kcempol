## Featured work

### People Portal

A team-built recruitment platform for the University of Maryland's App Dev Club. My contributions include a Python/FastAPI profile-photo screening service using OpenCV YuNet, a presigned Amazon S3 upload flow, backend security reviews, and React/TypeScript interface improvements.

[Backend](https://github.com/kcempol/PeoplePortalServer) · [Frontend](https://github.com/kcempol/PeoplePortalUI) · [Deployment](https://github.com/kcempol/PeoplePortalDeploy)

### Local Scribe

A private, local-first application that records or uploads audio and video, creates searchable transcripts with faster-whisper, and generates transcript-grounded study notes with Ollama.
